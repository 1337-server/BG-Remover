💡 How it Works

When you upload a photo, an AI model analyzes every pixel to find the main subject (for example, a person or an object) and separates it from the background.

It then creates a new image with the background removed — usually transparent — so you can reuse it anywhere (design projects, thumbnails, product listings, etc.).

If you have a GPU, the process runs on your graphics card, which can be 5-10× faster. If not, it runs on your CPU — slower, but identical in quality.

You can experiment with the settings above. Nothing is permanent until you save the result, so feel free to try different models and edge smoothness levels to see what looks best.

            🧠 How batch processing works
            

              
Point the tool at a folder and it scans every supported image, removing backgrounds one after another using your chosen settings.

              
Each file keeps its original name with a _no_bg suffix (or goes into a ZIP if you enable that option), so nothing gets overwritten.

              
Processing happens on the server. If a GPU is available, large folders finish much faster; otherwise the CPU handles the work with the same quality.

              
You can re-run the same folder whenever you update the settings — previous outputs stay intact unless you replace them manually.
