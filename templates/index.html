💡 How it works ▾

When you upload a photo, an AI model analyses each pixel to separate the main subject from the background.

The result is a new image with the background removed — usually transparent — so you can reuse it for designs, thumbnails, or product listings.

Processing runs on the server's CPU. Faster processors complete batches more quickly, but every image receives the same high-quality mask.

Experiment with the settings above — nothing is permanent until you save the result.

                  🧠 How batch processing works
                  ▾
                
                

                  
The tool scans every supported image in the folder and removes backgrounds using your chosen settings.

                  
Each file keeps its original name with a _no_bg suffix (or goes into a ZIP if enabled), so nothing is overwritten.

                  
Processing happens on the server, ensuring consistent results even without dedicated graphics hardware.

                  
Re-run the same folder whenever you update the settings — previous outputs stay intact unless you replace them manually.
